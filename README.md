# BrowserScreen VFX

Placa de croma verde, azul o gris con marcas de track para filmar pantallas de celulares y computadoras. Puede quedar fija aunque la toquen, abrir el teclado real del dispositivo para planos de manos escribiendo, o scrollear sin fin con marcas que siguen el dedo y 4 círculos fijos para el corner pin. Funciona en el navegador, sin instalar nada.

**Usar:** https://jswamp.github.io/browserscreen_vfx/

En iPhone, para que abra en pantalla completa: Safari › Compartir › Agregar a inicio, y abrirla desde ese ícono.
